# יומן הזמנות – מדמון במירון

אפליקציה להתקנה (PWA). הנתונים נשמרים ב-Supabase (פרויקט madmon-yoman), והאתר מתארח ב-Netlify (madmon-yoman).

- `index.html` – היומן
- `sb-store.js` – חיבור למאגר וכניסה עם מייל וסיסמה
- `sw.js`, `manifest.webmanifest`, `icons/` – התקנה במסך הבית ועבודה בקליטה חלשה

אין שלב בנייה: Netlify מפרסם את התיקייה כמו שהיא.
